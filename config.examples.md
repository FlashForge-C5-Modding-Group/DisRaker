# Examples for printer configs
## Creator 5 Pro:
Temperature objects for FlashForge Creator 5 Pro stock. 
Replace the temperature objects with these:
```
      "heater_generic chamber_heater",
      "extruder",
      "extruder1",
      "extruder2",
      "extruder3",
      "heater_bed"
```
The Extruders start with no number to 3, coordinating to 1 to 4.

## Creality K1/C/M
Temperature objects for Creality K1 stock & SAF. 
Replace the temperature objects with these:
```
      "extruder",
      "heater_bed"
```
The fan & chamber temperature sensor should automatically add itself.
